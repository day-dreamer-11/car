# 智能小车 · 巡线 / 机械臂 / 避障

一个集 **自动巡线**、**机械臂抓取**、**超声波避障** 于一体的智能小车项目。

## 功能模块

### 1. 巡线（Line Following）
小车通过底部的循迹传感器（红外对管 / 灰度传感器）实时检测地面黑线位置，
主控根据左右传感器的偏差调整两侧车轮差速，使小车沿预定轨迹稳定行驶。
- 直线段保持居中，出现偏差时差速纠偏
- 弯道根据偏差量自动增大转向力度
- 支持直角弯、S 弯、环线等连续循迹

### 2. 机械臂（Robotic Arm）
在小车平台上搭载多自由度机械臂，用于抓取 / 搬运目标物。
- 舵机驱动各关节，通过 PWM 信号控制角度
- 可完成抬升、伸出、夹取、放下等动作序列
- 与巡线配合：到达指定位置后执行抓取任务

### 3. 避障（Obstacle Avoidance）
通过超声波 / 红外测距传感器感知前方障碍物的距离。
- 障碍物进入设定阈值时自动减速或停车
- 根据左右两侧距离选择绕行方向，自动转向避开
- 障碍物移除后恢复巡航

## 系统组成

| 部分 | 说明 |
| --- | --- |
| 主控 | 单片机 / 嵌入式主控板 |
| 驱动 | 直流减速电机 + 电机驱动模块 |
| 传感 | 循迹传感器、超声波测距、红外避障 |
| 执行 | 舵机机械臂 |

## 运行说明

1. 将小车置于赛道起点，使黑线位于循迹传感器中间
2. 上电后小车进入巡线巡航模式
3. 到达抓取点后，机械臂执行抓取 / 放置动作
4. 前方遇到障碍物时自动避障绕行，通过后恢复巡线
